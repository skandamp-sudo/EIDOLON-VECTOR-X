Base release: `43e8830fa94a1169af20de33bb1b2df54d491873`, tagged `v1.0.0-convergence`. Design review takes place on `feature/visual-overhaul`.

Use a narrow navigation rail and a compact command bar. On small screens keep legacy tools reachable and move the full directory into a drawer. The first screen should identify the operator’s task, the relevant evidence and the next action.

Use #080B12 for the canvas, #101722 and #182233 for surfaces and #293548 for rules. Use light text, teal for active controls, violet for semantic transformations, amber for limitations and red for failures. Use system fonts, tabular digits and visible focus. Keep plots accompanied by readable numbers or source passages. Never fill missing observations.

Mission shows live probe coefficients. Inventory shows actual event allocations and missing quantities. The atlas uses its existing fitted frame. Research charts draw from versioned artifacts. Compare 1440×900, 1280×800, 390×844 and 360×800 against the engineering release.
